# M2.4 source-scoped environment artwork loading

The approved library-palette adaptation applies only to the exact archive map and four original CACITY sources. Environment HD originally checked raw members and declared palette hashes without checking the current map's effective art palette. Library-authored artwork would therefore also bind to the same raw image on an unrelated map using its prior Unit palette. New optional family `sourceScope` constraints prevent this bounded color adaptation from leaking into other maps.

A scoped family requires both its verified official source SHA-256 and the complete applied visual-adaptation status. The loader checks these before reading native/payload data or allocating textures, and returns the complete Original family with an explicit reason on refusal. Existing families without a scope retain their previous path. GameLoader records the immutable per-game source/adaptation context; GameScreen passes that context into the environment loader. It is not stored on shared theater instances, so map changes or overlapping loads cannot inherit another game's scope. Original maps, rules, owner indices, geometry, timing, resource budgets and prepared index are unchanged.

Three scope tests pass nine assertions, covering the exact approved source, incomplete atomic adaptation, unrelated maps, overlapping game contexts and unrestricted accepted families. A real loader test passes eleven assertions: scope refusal performs only the selection request, publishes no override and charges zero bytes before native or PNG allocation. Entry type checking passes. A preliminary theater-context approach was replaced before commit with per-game context to avoid shared-state races. No new CACITY HD family is published yet; new-family native validation will cover both densities and both admitted editions, with reuse explained for identical source paths. Earlier Batch23 runtime remains the frozen `9c149f0` HTML-only checkpoint; these later shared-path changes require their own incremental validation. Windows is not run.
