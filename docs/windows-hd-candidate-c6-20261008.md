Inputs are cloned without transfer, retaining original RGBA buffers for identical CPU fallback on worker construction, transport, calculation or timeout failure. A broken worker is terminated and not retried within that resolution. Borrowed subviews are bounded to page bytes before posting. Each raw 2048x2048 RGBA pair adds up to 32 MiB of temporary worker input copies; copying a borrowed subview can add a temporary main-thread copy too. This is transient CPU memory, not prepared-cache residency or actual VRAM. One request per worker is allowed. Workers terminate at the end of every resolution attempt, including success, observed cancellation, density retry and failure; requests time out after 15 seconds. Unit-family cancellation now reaches the asynchronous sprite preparation, and cancellation is checked before creating pooled textures.
