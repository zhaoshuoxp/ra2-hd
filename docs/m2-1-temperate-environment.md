## Native pipeline and override contract

Map `tileNum/subTile` -> edition theater INI -> `TileSets/TileSetEntry` -> resolved TMP/random variant -> `TmpFile/TmpImage` -> `TmpDrawable` indexed coverage -> atlas -> `SpriteUtils` billboard geometry -> merged `MapTileLayer`. Per-cell `LightingType.Full` multiplication is retained. `MapSurface` independently supplies ramp heights and receives shadows. Native animations, sprite/overlay and shroud layers remain separate.

`TmpImage` decodes native Z bytes, but the predecessor TMP draw path does not consume them as per-pixel depth. Preserve that handling without introducing a Z reinterpretation. Billboard vertices, extra-image trims/offsets, ramp/elevation metadata, transparency and depth behavior remain native. `MapSurface`, camera, picking and placement geometry are unchanged. Texture density and framebuffer resolution are separate.

The `tmp-terrain-hd-v1` contract binds edition/theater, resolved member hash, every subtile, grid/block/logical dimensions, offsets/origin, height/terrain/ramp metadata, extra region, Z/extra flags and radar metadata. A source-pinned desktop selector checks manifest identity. Runtime validates source identities, atlas hash/size/rects and exact expanded native alpha for an entire group before publication. Missing/corrupt/mismatched/canceled/over-budget groups use Original; a 4X request never silently uses 2X.

`GameScreen` prepares encountered groups behind the existing loading screen using existing Original/2X/4X preferences. Native identities are reusable across maps. `MapTileLayer` batches by shared atlas texture, with no texture per placed cell; lighting updates retain native-cell indices within each batch. Match ownership disposes textures/data/bindings. The building-prepared index and worker contracts, sidebar and independent UI path are unchanged.
