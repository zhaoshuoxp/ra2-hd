Red Alert 2 HD v0.2 - Complete and modular packages

For this Mac: unzip RA2-HD-v0.2-macOS-arm64-full.zip and move its single
Red Alert 2 HD.app into Applications. The complete resources are inside it.
No sibling folders or launcher script are needed.
For Windows: unzip RA2-HD-v0.2-Windows-x64-full.zip, keep its entire folder,
and run Red Alert 2 HD.exe.
Both complete archives work offline with their included resources.
Do not run an app directly from a ZIP. Wait for cloud downloads to complete.

Small platform program ZIPs are intended for a later modular distribution.
They need ALL matching private resource parts, extracted together into the
user-data directory listed in the program package's START-HERE.txt.
Private resource parts contain imported original game data; no public release
is authorized by this packaging task. Upload to private storage as appropriate.

SHA256SUMS.txt records the complete archives and resource parts.
Mac: local ad-hoc signing, no Apple Developer ID notarization.
Windows: static package checks only, native testing still pending.
Saved games and settings remain in the normal per-user application profile,
outside the application bundle. Updating or moving the app preserves that profile.
Private user profiles and saves are not included in these archives.
